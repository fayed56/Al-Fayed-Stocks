# تحديث التوصيات بسهولة

الملف المسؤول عن التوصيات هو:
`recommendations-data.js`

لتغيير سهم أو إضافة فرصة:
1. افتح الملف.
2. عدّل `symbol`, `name`, `type`, `entry`, `target`, `stop`, `status`, `note`.
3. ارفع الملف إلى نفس مكان `recommendations.html` في GitHub.

الحالات المتاحة: `مفتوحة` / `مغلقة` / `مراقبة`.

لا تضع مفاتيح API أو بيانات سرية في هذا الملف؛ فهو ملف عام على GitHub Pages.

# Al Fayed Stocks — Pro Website

نسخة احترافية متعددة الصفحات مستوحاة من بنية الموقع المرجعي من حيث فكرة: خدمات الأسواق، التحليلات، الأخبار، الرؤية والتواصل، مع هوية مستقلة.

## الصفحات
- index.html — الرئيسية
- saudi.html — السوق السعودي
- usa.html — السوق الأمريكي
- analysis.html — التحليلات
- news.html — الأخبار
- watchlist.html — قائمة المراقبة المحلية

## مهم قبل الإطلاق
هذه النسخة Front-end جاهزة للتصميم والعرض، وليست نظام تداول أو مصدر أسعار لحظية.
لإطلاق نسخة تجارية فعلية:
1. اربط API موثوقًا لأسعار السوق.
2. أضف Backend وقاعدة بيانات.
3. اربط نموذج التواصل بالبريد/CRM أو WhatsApp Business.
4. أضف نظام أعضاء واشتراكات إذا أردت محتوى مدفوعًا.
5. ضع بيانات الشركة والتراخيص والتنبيهات القانونية المناسبة قبل نشر توصيات استثمارية مدفوعة.
